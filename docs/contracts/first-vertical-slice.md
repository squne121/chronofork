# 最初のプレイアブル縦断経路

- **状態:** 実装順序と完了条件（技術計画）。ゲーム規則は `docs/spec/mvp-spec.md`、型・責務は `mvp-implementation-contract.md`、承認待ちは `docs/spec/pending-approvals.md`。
- 根拠: DEC-027/028/033/036/038/042、MVP 仕様 §12（工程 0〜4）。

## 1. 目標経路

**介入 → 人物の婚姻判断 → A 合法婚姻 → C 出生枠/B 出生 → A 王朝帰属と継承 → 1350 年の Title＋実効統治判定 → 比較 UI**

- 年初に `pair.trust` 等を変えると B-004/B-005 の候補スコア・採否が変わり得る。A-LEG-01 は適法な婚姻のみ登録。B-002 は C-004 の出生枠を請求し、A-DYN-02 が証拠付きで子の法的王朝所属を判断。死亡・世代交代から A-SUC-04 / A-TIT-07 へ接続。1350 年 Goal は最初から厳格な法制判定を使う。
- C-001〜009 の必要最小限の実処理で生活・生産・税・人口・支持を更新し、UI に `group.unrest`・`region.productivity` 等の安全な数値候補を追加できる。
- D の初期 `deFactoControllerRef` / 主権は常に参照するが、**D の戦争・外交はこの縦断の必須依存ではない**。未実装の D ルールは静かな固定イベントで代用せず `TODO` を明示する。
- 固定イベント禁止: 特定年・特定人物の強制成功/断絶、原史敗北や勝利経路のハードコードは行わない。A0 の自然敗北と通常介入の勝機は**実行して初めて判定**する。

優先して実装するルール（37 件の登録が前提）:
`B-009`, `B-004`, `B-005`, `A-LEG-01`, `RULE-C-004`, `B-002`, `B-003`, `B-001`, `A-DYN-02`, `A-CLA-03`, `A-SUC-04`, `A-TIT-07`, `RULE-C-009`、必要に応じ `RULE-C-001/002/003/005/007/008`、王位の単独検証に `A-SUC-05`。依存で必要になったものだけ前倒しする。

## 3. 第 1 縦断の完了条件

- [ ] デスクトップ 1280px で A0 → 過去年に介入 → A1 を 1350 年まで再計算 → 両史の比較 → Trace の確認ができる。
- [ ] 数値 modifier によって**実際に B の判断候補・採否が変わった根拠**と A の婚姻/法的状態の Event を辿れる。何も変わらなかった枝の Trace も表示する。
- [ ] 1350 年の勝敗は実 WorldState に対する厳格な Goal で評価され、勝敗を直接設定しない。
- [ ] 同 seed の再実行とリロード後の再計算で結果が同一。人口/人物/Title の不変条件を満たす。
- [ ] 年次・分岐・保存・実ルール・1350 年勝敗を結ぶ短い Playwright 操作経路が PASS（実測）。単なる機能モックや 100 年一律のダミー年表は不合格。
- [ ] 完了報告に、実行したコマンドと exit code、PASS/FAILED/UNVERIFIED、seed、scenario/ruleset/legal/rng の版、RuleID の実装一覧/未実装一覧、`CALIBRATION_ONLY` の値、残した未決ゲーム仕様（GAME-01〜05）を含める。未達なら「第 1 縦断未完」と報告する。

動作する第 1 縦断が実機で確認できたらいったん止める。全 37 ルール、複雑な経済/戦争、設計文書の網羅は先に求めない。原史敗北・勝利経路・面白さは実測と本人の試遊まで未達と報告してよい。

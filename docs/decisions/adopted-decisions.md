# 採用済み決定記録（DEC）

Project Chronofork の採用済み決定のうち、実装・仕様解釈に必要なものを要約する。移行元は移行前の企画資料「決定事項・未決事項ログ」（最終更新 2026-10-30、DEC-001〜048）。
**本ファイルは DEC-001〜048 の全件記録ではなく、実装に関係する主要決定の抜粋**である。新規決定は GitHub で管理し、旧 Drive の全履歴は移行前の記録として保管する。
**本ファイルが GitHub `main` 上の正本**（DEC-041）。変更・廃止した決定も消さず履歴として残し、新規決定は新しい ID を発行する。未承認の提案（PRO-xxx）を承認なしに「確定」へ昇格させない。

分類: **仕様** = ゲーム仕様として採用 / **技術** = 技術・運用方針 / **置換** = 後続 DEC に上書きされた部分あり。

**採用範囲と未決事項:** DEC-059/060では婚姻に伴う家門間政治同盟の自動成立と、その関係が判断に影響する原則を採用。DEC-062では、国内法に違反する援軍も自律選択でき、主君による処罰・政治的不利益が生じ得るという原則を追加採用。いずれも実際の援軍行動や処罰を自動確定するものではない。婚姻の成立要件自体は既存DEC-055/057/058とGAME-01〜03の承認範囲を尊重し、縁談の提案・交渉段階で同盟を先取りしない。**同盟の持続・終了、協力義務、国家間同盟との区別等は当初PR #79の時点では未承認だったが、後続の上位方針の採用はDEC-177に記録する。** 具体的な軍事援助・外交義務、離婚制度、共有型・Event/Trace契約、MVP適用時期は未決のままとする。DEC-060/062/063/064により、同盟を判断入力とすること、違法でも援軍を選択できること、違反判定と処罰判断の分離、法的に正当な処罰には負の評価を付けず法的根拠が確認できない処罰には負の評価が生じ得る原則は採用された。ただし、**義務が発動する条件**（国内の家門間紛争と国家間戦争の区別を含む）、国内法上の合法／違法の具体判定、援軍の成立条件、主君・法執行者の処罰権限とその根拠、裁量・実際の罰則、評判の変動量や影響対象、同盟解消条件、実装時期は未決であり、ここから勝手に実装しない。

**既存MVPとの境界:** DEC-059/060/062/063/064はゲーム規則の原則に関する意思決定。『亡国の王冠』の勝利条件、1250〜1350年の自動再計算、数値介入規則や正式シナリオデータを変更したものではない。既存ルール・コード・共有型へ反映するときは、残る詳細の決定と実装計画を別途照合してPR化する。

## 再計算テンポ・世界生成・保存の方針（2026-11-08）

**ユーザーの明示的な意思表示に基づく範囲限定の決定。** MVP『亡国の王冠』の1250〜1350年、固定シード検証、ゲーム規則・Goal・GAME-01〜05・既存の第1縦断の完成条件を変更しない。具体的なアルゴリズム、世界生成仕様、セーブ形式、演出仕様、性能閾値は未決。

| DEC-067 | **原史A0の再利用をMVP限定で認める。** 同一の初期状態・seed・シナリオ/法制/校正・ルール/RNG版等に限り、試遊で介入を繰り返す際のA0再計算を省く性能最適化を進める。異なる条件の結果を流用しない。製品版で単一の固定A0を新規ゲーム間に使い回す前提は採用しない。 | 技術方針／MVP限定 |

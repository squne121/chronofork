**本ファイルは DEC-001〜048 の全件記録ではなく、実装に関係する主要決定の抜粋**である。新規決定は GitHub で管理し、旧 Drive の全履歴は移行前の記録として保管する。
**本ファイルが GitHub `main` 上の正本**（DEC-041）。変更・廃止した決定も消さず履歴として残し、新規決定は新しい ID を発行する。未承認の提案（PRO-xxx）を承認なしに「確定」へ昇格させない。

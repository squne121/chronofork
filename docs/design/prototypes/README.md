## 参考にする体験
年代記（左）と簡略世界図（右）を同じ机で観測する。隅の時間操作で再生・停止・年移動し、対象のホバー／クリックから資料を重ね、関連人物・集団・家系・判断根拠へ移動する。比較も独立資料として同じ机に置く。排他的なモード切替、画面下部への専用調査領域の増設、装飾的なゲームタイトル・ヘッダーは不採用。

**このHTMLは操作の参照資料であり、製品コード・正式仕様・実シミュレーションではない。** 内部の戦争・増税・反乱・王朝断絶、人物、A1、因果説明は架空のUI fixture。観測による後付け生成、未承認介入、Goalの判定や実際の歴史データの根拠に使わない。ホバー遅延、固定操作、個別時点固定、画面比率、配色等は試験設定。高度な窓管理・配置永続化・3D・本格美術は製品版。採用範囲は承認済みmainの仕様・決定記録で確認する。UI実装の担当は #154/#156/#155/#157、シミュレーションの担当は #71。HTMLのコードを本体へ丸ごと移植しない。

# MVP仕様『亡国の王冠』（承認済み）

- **状態:** 承認済みの MVP 最小仕様。根拠は `docs/decisions/adopted-decisions.md`（DEC-012〜014/020〜025/028/030〜037）。移行元は企画資料「MVP 最小仕様書 v0.4」。
- 数値・係数は初期ベースラインであり、試遊結果に応じて調整してよい。**ゲーム規則（判断・効果・勝敗）の変更は DEC を追加してユーザー承認を得る。**
- 未決・未承認の事項は `pending-approvals.md`。技術契約は `docs/contracts/`。

## 1. 目的と体験

プレイヤーは統治者ではなく、歴史へ間接的に介入する存在。**原史を観測 → 原因を推測 → 過去の対象に介入 → 1350 年まで自律再計算 → 原史と改変史の差分・因果を調べる → 再挑戦**。
優先順位: ①目標達成のための試行錯誤の手応え ②介入が共通ルールを通じて説明可能な結果を生むこと ③同じ世界から多様な結末が生まれること。史実再現・パラメータ数・グラフィック量は優先しない。
勝利条件の抜け道（臣従、領土縮小、政略結婚、傍系継承等）を「正解の一種」とし、特定ルートへ誘導しない。条件を満たさない表示バグ・データ破損は不具合として直す。

## 3. 勝利と敗北

**勝利:** 1350 年に、ナルヴェン王朝の正統な構成員が 1 人以上、次をすべて満たす。
`alive && legalDynastyId == NALVEN && hereditaryTitle.valid && hereditaryTitle.hasTerritorialControl && hereditaryTitle.regionId が存在`

- 独立・王号・エルディア国土の維持は不要。属国/外国封臣としての世襲所領、王国滅亡後の小領地、合法な傍系/母系も勝利。
- 血縁者の生存のみ、空の称号、非世襲の官職、認められない自称領主は**敗北**。
- 血統（dynasticBloodline）・法的王朝所属（legalDynastyId）・家名は別データ。家名の文字列置換では突破できない。婚姻契約・正当な継承による合法的な帰属変更は可能。
- 独立/属国/外国領、保有地域数、王号の有無、存続年数、家系生存者数は表示するが勝敗を上書きしない。1292 年の断絶は参考値であり、エンジンで強制しない。

## 4. 年次処理（固定順序）

各年 t（1250〜1349）の年初に有効な介入 modifier を解決し、次を順に処理して t+1 の状態を作る。1350 年は評価専用で①〜⑦を実行しない。

① 天候・生産・人口・財政 → ② 地域・集団の不満と家門支持 → ③ 重要人物の婚姻・外交・政治的意思・出生と死亡 → ④ 相続・継承・称号承認 → ⑤ 反乱・クーデター・領地支配の変更 → ⑥ 国家間の軍事圧力・和平・属国化 → ⑦ イベント・因果ログ記録。

- 各工程は状態を入力とし、**実際の状態変化のみ** EventLog に記録。重要判断（候補・前提・選択・不採用理由・乱数）は DecisionTrace に別記録し、状態が変わらなかった判断も残す。
- 介入は「支持率 → 勝利」のように直接変換しない（例: 婚姻を望む → 家門の利害と関係が合う → 制度が許す → 成立）。
- 構造的原因が残れば首謀者が変わっても別の危機が起きてよい。事件は「1292 年に必ずクーデター」のような固定進行にしない。
- 敗戦即王朝断絶にしない。併合/従属/講和は財政・軍事・支持・相手の動機で決まり、従属領として残る経路を許す。

## 5. 介入（数値への直接補正）

- プレイヤーは年・対象（人物/人物ペア/家門/集団/国家/地域）・**数値項目**を選び、その数値に一時 modifier を与える。結果イベントは強制せず、自律ルールで成立する。
- 数値項目は `StatDefinition` に登録（意味・値域・参照するルール）。項目数に上限はなく、**ルールが実際に参照する数値**を順次追加する。総介入回数は無制限、PT なし。
- **直接編集不可:** 法的王朝所属、称号の合法性/承認、婚姻・反乱の成立、勝利フラグ、世界共通ルールの係数、相続法。保存則のある値（人口、国庫、兵力、家門支持比率）は専用の台帳・正規化を通さず生値を書き換えない。
- 初期検証例（上限ではない）: 人物間信頼 +20/5 年、集団不満 −15/8 年、統治者の融和選好 +20/8 年（介入時の統治者本人。交替後に継承しない）、地域生産力 +10/5 年。補正量・期間の既定値は暫定で、試遊して調整する。
- 同年・同対象・同一数値への同一操作の再送は重複として拒否。別項目・別対象・別年は保持。プレビューには対象・年・数値の前後・期間・影響する判断を示す。

## 6. 歴史分岐

- 新規開始時に介入なしの原史 A0 を計算・保存。過去年 t への介入で A1、A2… を作り、**t 年初から 1350 年まで自動再計算**する（途中停止なし）。
- t より前の過去、および t 年の別項目・別対象の有効介入は保持。t より後の旧介入と旧未来は引き継がない。プレビュー文言: 「この年より後の旧介入と未来は引き継がれません。同年の別項目への有効介入は残ります」。
- A0・A1 など過去の歴史は読取専用の比較用。再アクティブ化・複数セーブスロットは不要。「新規ゲーム」は確認付きで介入台帳を初期化する。
- 乱数: 既定シード固定（例 20261028）。`year/process/entityId/eventKey` から安定生成し、分岐で全乱数を引き直さない。新人物 ID は親・出生年等から決定的に付与する。

## 7. GUI 最小機能（デスクトップ 1280px）

- 上部: シナリオ目標・1350 年判定・現在の歴史（A0/A1…）。PT 表示/警告はなし。
- 左: 6 地域の簡略マップ/接続図（支配者・属国関係を表示）。中央: 年スライダー・年代記・重大事件。右: 選択年の国家・集団・人物・称号・家系と介入フォーム。下部/専用画面: 2 つの歴史の比較。
- 比較の最低限: 王朝存続・称号・所領・宗主国、家門支持と不満、婚姻・死亡・継承、重大事件年。差分から前提の状態・判断・介入へ遷移できる。因果が確定できない場合は断定せず「関連する条件」と表示。
- 文章は内部状態から生成。実行時 LLM なし。年表の文章だけに存在する出生・戦争・人物を作らない。勝敗後も閲覧・比較・過去への再介入を継続できる。

## 9. 完成条件・品質・対象外

- **機能的完成:** ①原史が介入なしで 1350 年まで進む ②各年の世界・人物・事件が閲覧できる ③複数の数値項目を選んで直接介入できる ④回数制限なしで再計算できる ⑤原史と改変史を比較できる ⑥変更した数値 → 判断の採否 → 年表イベント → 王朝存続の因果を UI で追える ⑦同条件で同結果。
- **品質テスト:** 値域と総和（人口・支持・資源）、家系/婚姻/生死/称号/主従/領土の整合、同年異項目介入の保持と後年旧介入の破棄、重複操作排除、同一シードでの WorldState/EventLog/DecisionTrace 一致、年表とログの一致、旧歴史の不正ロード防止、保存則のある値の無検証直接変更の拒否。
- **勝利条件テスト（単体で固定）:** 独立王＋所領＝成功／外国臣下＋世襲所領＝成功／傍系が合法に領主を継承＝成功／血縁者のみ＝失敗／名目称号＝失敗。
- **ゲーム性の評価:** 開発者本人の実プレイ（DEC-018）。A0 敗北と通常介入による勝利経路の存在は実機調整で確認するまで未検証として扱う。
- **対象外:** Steam 配信、価格、寄付、オンライン、スマホ最適化、3D、全個人エージェント、リアルタイム戦闘、他時代、技術ツリー、宗教/芸術の詳細、複数シナリオ、自由文介入、実行時の生成 AI 年代記、一般向けシナリオエディタ、サポートメニュー、PT。

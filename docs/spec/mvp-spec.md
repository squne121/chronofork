# MVP仕様『亡国の王冠』（承認済み）

- **状態:** 承認済みの MVP 最小仕様。根拠は `docs/decisions/adopted-decisions.md`（DEC-012〜014/020〜025/028/030〜037）。移行元は企画資料「MVP 最小仕様書 v0.4」。
- 数値・係数は初期ベースラインであり、試遊結果に応じて調整してよい。**ゲーム規則（判断・効果・勝敗）の変更は DEC を追加してユーザー承認を得る。**
- 未決・未承認の事項は `pending-approvals.md`。技術契約は `docs/contracts/`。

## 1. 目的と体験

プレイヤーは統治者ではなく、歴史へ間接的に介入する存在。**原史を観測 → 原因を推測 → 過去の対象に介入 → 1350 年まで自律再計算 → 原史と改変史の差分・因果を調べる → 再挑戦**。
優先順位: ①目標達成のための試行錯誤の手応え ②介入が共通ルールを通じて説明可能な結果を生むこと ③同じ世界から多様な結末が生まれること。史実再現・パラメータ数・グラフィック量は優先しない。
勝利条件の抜け道（臣従、領土縮小、政略結婚、傍系継承等）を「正解の一種」とし、特定ルートへ誘導しない。条件を満たさない表示バグ・データ破損は不具合として直す。

## 3. 勝利と敗北

**勝利:** 1350 年に、ナルヴェン王朝の正統な構成員が 1 人以上、次をすべて満たす。
`alive && legalDynastyId == NALVEN && hereditaryTitle.valid && hereditaryTitle.hasTerritorialControl && hereditaryTitle.regionId が存在`

- 独立・王号・エルディア国土の維持は不要。属国/外国封臣としての世襲所領、王国滅亡後の小領地、合法な傍系/母系も勝利。
- 血縁者の生存のみ、空の称号、非世襲の官職、認められない自称領主は**敗北**。
- 血統（dynasticBloodline）・法的王朝所属（legalDynastyId）・家名は別データ。家名の文字列置換では突破できない。婚姻契約・正当な継承による合法的な帰属変更は可能。
- 独立/属国/外国領、保有地域数、王号の有無、存続年数、家系生存者数は表示するが勝敗を上書きしない。1292 年の断絶は参考値であり、エンジンで強制しない。

## 4. 年次処理（固定順序）

各年 t（1250〜1349）の年初に有効な介入 modifier を解決し、次を順に処理して t+1 の状態を作る。1350 年は評価専用で①〜⑦を実行しない。

① 天候・生産・人口・財政 → ② 地域・集団の不満と家門支持 → ③ 重要人物の婚姻・外交・政治的意思・出生と死亡 → ④ 相続・継承・称号承認 → ⑤ 反乱・クーデター・領地支配の変更 → ⑥ 国家間の軍事圧力・和平・属国化 → ⑦ イベント・因果ログ記録。

- 各工程は状態を入力とし、**実際の状態変化のみ** EventLog に記録。重要判断（候補・前提・選択・不採用理由・乱数）は DecisionTrace に別記録し、状態が変わらなかった判断も残す。
- 介入は「支持率 → 勝利」のように直接変換しない（例: 婚姻を望む → 家門の利害と関係が合う → 制度が許す → 成立）。
- 構造的原因が残れば首謀者が変わっても別の危機が起きてよい。事件は「1292 年に必ずクーデター」のような固定進行にしない。
- 敗戦即王朝断絶にしない。併合/従属/講和は財政・軍事・支持・相手の動機で決まり、従属領として残る経路を許す。

## 5. 介入（数値への直接補正）

- プレイヤーは年・対象（人物/人物ペア/家門/集団/国家/地域）・**数値項目**を選び、その数値に一時 modifier を与える。結果イベントは強制せず、自律ルールで成立する。
- 数値項目は `StatDefinition` に登録（意味・値域・参照するルール）。項目数に上限はなく、**ルールが実際に参照する数値**を順次追加する。総介入回数は無制限、PT なし。
- **直接編集不可:** 法的王朝所属、称号の合法性/承認、婚姻・反乱の成立、勝利フラグ、世界共通ルールの係数、相続法。保存則のある値（人口、国庫、兵力、家門支持比率）は専用の台帳・正規化を通さず生値を書き換えない。
- 初期検証例（上限ではない）: 人物間信頼 +20/5 年、集団不満 −15/8 年、統治者の融和選好 +20/8 年（介入時の統治者本人。交替後に継承しない）、地域生産力 +10/5 年。補正量・期間の既定値は暫定で、試遊して調整する。
- 同年・同対象・同一数値への同一操作の再送は重複として拒否。別項目・別対象・別年は保持。プレビューには対象・年・数値の前後・期間・影響する判断を示す。

## 6. 歴史分岐

- 新規開始時に介入なしの原史 A0 を計算・保存。過去年 t への介入で A1、A2… を作り、**t 年初から 1350 年まで自動再計算**する（途中停止なし）。
- t より前の過去、および t 年の別項目・別対象の有効介入は保持。t より後の旧介入と旧未来は引き継がない。プレビュー文言: 「この年より後の旧介入と未来は引き継がれません。同年の別項目への有効介入は残ります」。
- A0・A1 など過去の歴史は読取専用の比較用。再アクティブ化・複数セーブスロットは不要。「新規ゲーム」は確認付きで介入台帳を初期化する。
- 乱数: 既定シード固定（例 20261028）。`year/process/entityId/eventKey` から安定生成し、分岐で全乱数を引き直さない。新人物 ID は親・出生年等から決定的に付与する。

## 7. GUI 最小機能（デスクトップ 1280px）

- 上部: シナリオ目標・1350 年判定・現在の歴史（A0/A1…）。PT 表示/警告はなし。
- 左: 6 地域の簡略マップ/接続図（支配者・属国関係を表示）。中央: 年スライダー・年代記・重大事件。右: 選択年の国家・集団・人物・称号・家系と介入フォーム。下部/専用画面: 2 つの歴史の比較。
- 比較の最低限: 王朝存続・称号・所領・宗主国、家門支持と不満、婚姻・死亡・継承、重大事件年。差分から前提の状態・判断・介入へ遷移できる。因果が確定できない場合は断定せず「関連する条件」と表示。
- 文章は内部状態から生成。実行時 LLM なし。年表の文章だけに存在する出生・戦争・人物を作らない。勝敗後も閲覧・比較・過去への再介入を継続できる。

### 通常婚姻・通常土地相続・新規統治委任の限定権限（DEC-057）

この節は**第1縦断の同一国家・通常法制の権限者**だけを定義する。国王個人が死亡・交替しても法制機関そのものは `COUNTRY` で表現し、国王の存在や国家IDから権限を推測しない。いずれの操作も法的授権と当年の判断を別の記録として残し、EventLog/DecisionTraceの因果参照を持つ。

| 対象 | 認証・発行権限者 | Aが確定できる最低条件 | それ以外 |
|---|---|---|---|
| 通常婚姻（`A-LEG-01`） | 両当事者が同一国家の法的管轄下にある場合、当該国家の法制機関（`ControllerRef {kind: COUNTRY}`） | 両人物が利用可能、現在の所属Houseに明示された `countryId` が同一、当該国家に `NORMAL_MARRIAGE` の有効な法令・授権記録、B-005の当事者間合意、重婚・親族等の審査、矛盾なく合意された契約とその証拠が揃うこと。契約条項が無くても合法な婚姻はあり得るが、その子の法的王朝は `UNDETERMINED`（DEC-055） | 管轄未確定、異なる国家、近親・年齢等の法的適格性が未審査、契約条件の競合、授権不明なら `DEFER`。既存のB-004スコアだけで法的婚姻を作らない |
| 通常の世襲土地相続（`A-SUC-04` → `A-TIT-07`） | 当該Titleの**現行主権国家の法制機関**（`COUNTRY`）。授与国・Title認定国との対応を審査 | `TERRITORIAL`・世襲・有効・承認済みで、明示授与・現行称号承認・ `NORMAL_LAND_SUCCESSION` の事前授権が揃う。G-03/04の合法な唯一の後継順位が検証可能で、競合請求・追加裁量がないときのみ当年の認証決定と `APPROVED` ケースを生成して移転 | 候補・権限・法的所属が未確定、同順位競合、主権の変化、王位や剥奪は `PENDING`。死亡年に決まらなくても後年再審査する |
| 相続後の新規統治委任（`CONTROL_MANDATE_SET`） | **当該地域の現在の実効統治者**（`Region.deFactoControllerRef`）。第1縦断の国内国家直轄地域では `COUNTRY` | 新Title保持者の適法な相続が確認され、委任者が現在の実効統治者であり、当該地域・Title・現行主権・認定国について**その実効統治者へ委任発行権を与えた明示の授権記録**と、当該保持者宛の新しい委任決定が一意に存在する。開始年・終了境界・source Eventを記録 | 権限欠落・支配者変更・主権変更・複数競合なら `DEFER`。古いMandateの受益者は変更しない。委任の有無は徴税先や国の主権を変更しない |

- 初期の法令・授与・権限委任は1250年以前の**明示された背景記録**として格納可能だが、1250年以降の婚姻・相続・新委任の**成立Eventを事前に予約しない**。権限記録はaction・issuer・jurisdiction・law/grant evidence・適用条件を実際に照合すること。発行者ID、Grant ID、sourceEventIdが単に非空であるだけでは成功扱いしない。
- 相続が完了したとき、旧Mandateは履歴として残すが、新保持者の委任に自動転用しない。**有効性の評価は現保持者・生死・現支配者・現主権・Title承認・期間と照合する**。旧保持者の死亡等で実効性を失ったMandateの記録が存在することだけを理由に、後継者への新たな合法委任を禁止しない。同時点で有効な競合委任は拒否する。
- `Goal`の1350年判定条件（本人の実効支配または有効な委任、存命の法的ナルヴェン構成員、世襲土地Title、現行主権下の承認）は一切緩和しない。初期8人・法令ID・Grant具体値は引き続き `experimental` と正式世界設定を区別する。
- **本節の対象外:** 王位の継承、国際婚姻・外国封臣、剥奪、主権変更後の再承認、Claimの争訟手続、1350年の正式Goal公開条件。**国内通常婚姻に限った成年・近親・複数契約案の交渉は次節DEC-058**で定義する。その他の未解決事項は `docs/spec/pending-approvals.md`。

## 8.1. 次世代の国内通常婚姻・家門契約交渉（DEC-058、MVP限定）

この節は**B-004/B-005 → A-LEG-01 → B-002 → A-DYN-02**の次世代への反復を定義する。1250年の8人限定の審査済みペア表から卒業し、実WorldStateから判定する。具体的な係数や試験用法令・人物設定は `CALIBRATION_ONLY`、国際婚姻・王位・外国封臣等は対象外。

### 1. 毎年の婚姻適格性

- B-004の評価対象は当年年初の実人物。初期人物・B-002の出生児・根拠付きB-001昇格人物を同じ基準で扱う。生存、男女1組（**現行B-002父母・出生モデルのMVP限定入力**）、双方満18歳以上、別人、同一の明示された`House.countryId`管轄、当年の有効婚姻に重複しないこと。婚姻年齢18歳はMVPの法的最低年齢であり、B-002出生確率・妊孕年齢の校正値とは区別する。
- 禁止する既知の近親関係は**すべての直系祖先・子孫、および双方が2世代以内に同一祖先を持つ関係**（全/半兄弟姉妹、叔父/姪、第一いとこ等）。親子グラフから判明した禁止関係は婚姻不可。**法的な禁親審査は記録上の関係と事前の適格性証拠を対象とする**。未記録の血縁を「血縁がない」と事実認定したり、自動生成したりしない。管轄に禁親の争訟・矛盾する証拠がある、または必要な適格性確認が欠ける場合は`DEFER`し、登録済みの親族関係が空欄というだけで勝手に法的審査済みとしない。
- 配偶者の死亡に基づく婚姻終了をAの法的状態・証拠として記録し、**翌年以降**は再婚候補にできる。婚姻の終了が未記録なら有効婚姻として扱い再婚しない。離婚・婚姻取消など別の解消制度はMVP対象外。
- 同じ年に1人へ複数の縁談意思がある場合、双方がそれぞれ相手を**唯一の最上位候補**として選ぶ場合だけB-005の契約交渉へ進む。順位は現年の相互信頼・家門支持と利害に基づき、ID並び順・固定人物番号では選ばない。得点同率、相手側の選好不一致、根拠不足は`DEFER`（自動配偶者指定は行わない）。

### 2. 子の法的王朝条項を含む契約合意

- 縁談が双方の意思で成立する見込みになったとき、B-005がその年の証拠から**明示的な契約案**を検討する。候補は①子の王朝帰属を指定しない無条項案、②いずれかの当事者に**実際にDETERMINED**している法的王朝への帰属を指定する案。両者が同じ王朝なら重複候補は1件へ統合する。未知の法的王朝・実在しない条項・父系デフォルトを作らない。
- **双方それぞれの契約案ごとの同意**を判定する。契約案の効用は、その年の相互信頼、出身家門・人口集団の実際の支持、既存Title/Claimと家門の継承利害、当該案が双方の将来の子に与える合法王朝を入力とする。具体的な効用重み・受諾閾値は`CALIBRATION_ONLY`だが、両者が受諾閾値を満たす案のうち**双方の低い方の効用を最大にする案が一意**である場合だけ合意成立。同率・双方不一致・証拠不足なら`DEFER`し、次年の変化を待つ。
- 無条項案も**双方が明示的に同意した場合だけ**採用し、子の法的王朝所属は引き続き`UNDETERMINED`（DEC-055）。ナルヴェン帰属案を勝利に都合がよいという理由で優先しない。プレイヤーは信頼・支持等の許可済み数値だけを介入でき、契約案や子の王朝・婚姻・勝利を直接指定できない。
- A-LEG-01はDEC-057に従い同年の婚姻権限・当事者適格性・B-005の**唯一の合意案と証拠**を再審査する。登録が成立して初めて契約ID・条項ID・証拠IDを婚姻へ固定する。出生時A-DYN-02は、実際に有効な婚姻契約の唯一の条項からのみ子の法的王朝を認定し、出生後に未合意契約へすり替えたり遡及変更したりしない。

### 3. 家系を複数世代へ延長する際の供給源と検証

- 初期人物8人とB-002で実際に生まれた子を優先して候補探索する。婚姻相手が不足する場合、B-001は**既存の家門・人口集団・年齢/出身コホートの出典と安定IDが検証できる場合のみ**人物を昇格させる。コホートや系譜の根拠が不足する場合は不足を診断し、適当な配偶者や勝ち筋を生成しない。人物は人口集団の内訳であり人口へ再加算しない。
- A0と同じseedのA1を別に再計算し、B-004/B-005の交渉・A-LEG-01婚姻・B-002出生・A-DYN-02帰属・A-SUC-04/A-TIT-07相続・ControlMandateをEventLog/DecisionTraceで辿る。1350年の実WorldStateを**既存`evaluateGoal`で厳格評価**し、固定年の子・婚姻・王朝断絶・勝利を発生させない。
- 受入検証では少なくとも「新生児が年齢到達後に適格性を審査された」「出生→成長→婚姻→次の出生という**実際の孫世代**が成立し得る」「契約合意の相違で子の法的王朝が変わり得る」「証拠欠落・同順位・近親・重婚・異国・二重契約が拒否/DEFER」「同seedの再実行完全一致」を確認する。A0敗北・A1勝利が自然発生しなければ**未実証**と報告し、Goalや規則を緩めない。

**対象外・保留：** 世界観上の歴史的婚姻年齢の精緻化、国際・宗教・身分制度による婚姻差、国際法制、複数配偶婚、親族婚の特別許可、離婚、母系/傍系のClaim争訟、人口コホート根拠のない自動人物生成、正式Goal公開ゲート。必要になれば別途決定する。

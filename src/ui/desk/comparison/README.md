# 編纂机の介入・比較（D2、#157）

通常入口の実 A0 から人物資料の「介入を検討する」を選ぶと、同じ編纂机に非モーダルの介入資料が開きます。フォームには調査起点の人物・年だけ（縁談から開いた場合はその相手も）引き継ぎます。補正値はプレイヤーが入力し、明示的に再計算を実行します。従来の検証入口と試験用の直接介入は別経路です。

- 調査起点の `HistoryYear`・対象・確認できた根拠と、実行した介入の入力および比較結果は別に保持します。比較年の変更は A0 の観測年も介入年も変更しません。「元の調査へ戻る」は起点年を再表示し、保存した出典の資料を開きます。
- 比較は `historyFromPlayView(view).compare(pair, year)`。A1→A2 の A1 は A0→A1 の A1 と同じ枝でも別の転送ビューです。比較の根拠リンクは受け取った `HistoryYear` をそのまま `openRequest.history` に渡します。関連窓への別年取得には、元の DTO オブジェクトから同じ `view` と `pair` を特定できた場合のみ `historyUpdate` を使います。普通の A0 観測や他の比較は不足分を補いません。
- 年初の実状態・年内記録・転送範囲を分け、記録差が空でも転送省略分を無かったことにはしません。1350 年の技術判定は正式勝敗と別です。
- 実ブラウザ縦断は `CHRONOFORK_E2E_DESK_PLAYTHROUGH=1` で `tests/e2e/desk-playthrough.spec.ts` を実行します。停止・失敗の明示 fixture を除き、通常入口の Worker を使用します。入力例は回帰試験専用で、ゲーム内の推薦ではありません。
